# Vextraction

Builds only. Vextraction is a PvP voxel-rig extraction game: build a rig block by block, drop into a shifting desert, mine, fight, and extract before the desert or another pilot takes it.

## Download

Grab the build for your machine from the latest release:

| Platform | File |
| --- | --- |
| macOS (Intel and Apple Silicon) | `Vextraction-macOS-universal.zip` |
| Windows x86_64 | `Vextraction-windows-x86_64.exe` |
| Windows arm64 | `Vextraction-windows-arm64.exe` |
| Linux x86_64 | `Vextraction-linux-x86_64` |
| Linux arm64 | `Vextraction-linux-arm64` |

macOS: the app is not notarized yet. After unzipping, right-click the app and choose Open the first time, or run `xattr -dr com.apple.quarantine Vextraction.app`.

Linux: `chmod +x Vextraction-linux-*` before running.

## Playing together on a LAN

One player picks Multiplayer, hosts, and shares the LAN IP shown. Everyone else picks Multiplayer, enters that IP, and joins. Every player needs the same version; the game checks `manifest.json` in this repository on launch and before every drop.
